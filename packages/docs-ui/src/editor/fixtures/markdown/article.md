# 鎌倉の古民家で「暮らすように働く」を始めた3人の話

鎌倉駅から歩いて12分。**築80年の古民家**を改修したシェアハウスに、この春から3人の住人が暮らしています。 今回は、住人の佐藤さん・田中さん・山本さんに、*移住のきっかけ*と、ここでの毎日について話を聞きました。

## 東京から鎌倉へ、通勤の1時間が変えたこと

佐藤さんが鎌倉に来たのは2025年の秋。都内の IT 企業で働きながら、週に2回は東京へ通っています。

> 「電車の1時間で、仕事のモードに切り替えられるんです。家に着く頃には、ちゃんと鎌倉の人に戻っている」

通勤を**負担ではなく区切り**として捉えるようになった、と佐藤さんは話します。

## 住人どうしの距離感

共用のキッチンでは、週末になると誰かが料理を始め、自然と人が集まります。

- 朝ごはんは各自で
- 夕ごはんは週に1回、みんなで作る
- 掃除の当番は月ごとに交代

「決まりは少ないほうが続く」というのが、3人の共通の意見でした。

## 地域とのつながり

山本さんは、近所の農家さんの**朝市**を手伝っています。

1. 土曜の朝6時に集合
2. 野菜を並べて、9時まで販売
3. 片付けの後に、みんなで朝ごはん

詳しくは [NIHO のサイト](https://niho.life/spots) で紹介しています。

## これから住む人へ

> 鎌倉の暮らしは、思っていたより忙しい。でも、その忙しさが楽しい。

見学は随時受け付けています。気になった方は、まず一度、遊びに来てください。
