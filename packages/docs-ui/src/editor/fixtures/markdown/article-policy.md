# 記事方針

## 核となるメッセージ

\*\*「通勤の1時間が、暮らしの区切りになる」\*\*という発見を軸にする。

## 想定読者

- 都内で働きながら、海の近くへの移住を考えている20〜30代
- シェアハウスに興味はあるが、人間関係に不安がある人

## 構成方針

1. 導入: 古民家と3人の住人の紹介
2. 本編
   - 通勤の1時間の話（佐藤さん）
   - 住人どうしの距離感（田中さん）
     - 夕ごはんは週に1回
     - 掃除の当番は月ごと
   - 地域とのつながり（山本さん）
3. 結び: 見学の案内

## 文体

- です・ます調。やわらかく、語りかけるように書く
- 発言の引用は `>` で短く残す
- 数字は算用数字にする（例: 12分、80年）

## 避けたい表現

- 「田舎暮らし」「スローライフ」などの決まり文句
- 移住を勧めすぎる表現
