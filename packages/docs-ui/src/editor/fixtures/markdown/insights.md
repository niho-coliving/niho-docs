## 事実

- 平日の昼間は、住人の3人中2人が家で仕事をしている
- 共用のキッチンは、夕方6時から8時に混む（3回）

## 意見

- 「決まりは少ないほうが続く」
- 「掃除の当番表は、紙で貼ってあるほうが見る」

## 要望

- 宅配の荷物を受け取れる場所がほしい（2回）
- 自転車を置ける屋根がほしい

## 困りごと

- 冬の朝、廊下が寒い
- ゴミの分別が地域によって違って分かりにくい

---

## インサイト1: 「決まり」より「見える化」を求めている

住人は細かいルールを嫌う一方で、**誰が何をしたか**が見える状態を好んでいます。 当番表を紙で貼る、という要望の背景には、催促しなくても回る仕組みへの期待があります。

> 「掃除の当番表は、紙で貼ってあるほうが見る」

## インサイト2: 在宅勤務が前提の住まい方（仮説）

昼間に家にいる人が多く、光熱費や音の問題が「在宅の人に寄る」ことを気にしています。

> 「在宅の日が多いので、エアコン代は少し多めに払ってもいい」
