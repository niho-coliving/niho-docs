# 新規作成の場所

2026-10-22 の仕様。

- アプリ全体の緑の＋は、選択中のフォルダや開いているページに依存せずホームへ作成する。メニューの題・読み上げ名は「ホームに作成」で、ページ・音声・フォルダを選べる。
- フォルダ行の＋は、押したフォルダへ追加する。題・読み上げ名は「〈フォルダ名〉に追加」で、ページ・音声を選べる。フォルダは入れ子にしない。
- Mac の ⌘N はホームにページ、⇧⌘N はホームに音声を作る。作成後はそのページを開き、ツリーでも選択する。
- ホームの音声は独立した録音ページとして作り、フォルダを自動作成しない。文字起こしと生成ページはその音声の下へ並べる。ホームには複数の音声を置ける。
- フォルダの音声は引き続き1セット。すでに音声があれば、追加メニューから背景情報の音声欄を開く。
- マイク録音は開始時の保存先ページを保ち、画面移動・アプリ再起動・保存の再試行でほかの音声へ混ぜない。保存先ページを持たない旧録音の復旧は既存の動作を維持する。
- ホームの音声・その生成ページを開いて音声をドロップした場合は、その音声へ取り込む。非同期の確認を待つ間にページを移っても、取り込み先を変えず選択を戻さない。
- Web/PWA ホストはこの共通ルールに接続する。ホスト固有の接続と公開版の取り込みは非公開側で行い、共通 UI の保存先をホスト側の選択状態から切り替えない。

保存形式の追加・データ移行は行わず、既存のホームのページ・録音の保存形式を使う。
