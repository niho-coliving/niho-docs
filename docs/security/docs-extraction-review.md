## 権利と境界の確認

- macOS の読み上げで生成された音声サンプルは公開履歴から除外する。録音のテストには公開可能な合成音を使用する。アイコンとモデルの notice は個別に確認する。
- 非公開のAPI・DB・認可・個人情報・AI予算・署名秘密鍵がコード、CIログ、成果物に含まれないこと。
- 非公開 `niho-app` のWeb/API/配布が、公開側Docsの変更不能な版を参照し、同じ版で契約と画面のテストを通すこと。

NIHO保有コードには、現時点で第三者への再利用許諾を付けない。
